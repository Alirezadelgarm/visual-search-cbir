# Changelog

## 1.0.0 - Portfolio release

- Refactored the original single-file Tkinter coursework application into a reusable Python package.
- Preserved the SIFT + Harris dual-BoVW retrieval design and Rocchio relevance feedback.

- Added class-based Precision@K and mAP@10 evaluation utilities.
- Added automated tests, Ruff linting, and GitHub Actions CI for Python 3.11 and 3.13.
- Added portfolio README, architecture documentation, resume bullets, and interview notes.
