# Resume bullets

## Visual Search / Content-Based Image Retrieval

- Built a content-based image retrieval application combining SIFT and Harris local features, dual Bag-of-Visual-Words vocabularies, L2-normalized histograms, and weighted cosine similarity to return top-10 visually similar images.
- Implemented interactive Rocchio relevance feedback that refines SIFT and Harris query representations toward user-selected relevant results through a Tkinter interface.
- Structured the portfolio version as a reusable Python package with index persistence, headless CLI workflows, quantitative retrieval metrics, automated tests, Ruff linting, and GitHub Actions CI.

## Core technologies

Python, OpenCV, SIFT, Harris corner detection, MiniBatch K-Means, Bag of Visual Words, cosine similarity, Rocchio relevance feedback, Tkinter, scikit-learn.
